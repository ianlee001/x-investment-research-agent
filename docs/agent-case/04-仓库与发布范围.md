## 排除内容

`.env` / `.env.local`、真实口令和 token、个人业务数据库、原始供应商 payload 和日志、`.runtime`、缓存、虚拟环境、node_modules、dist、浏览器 trace / test-results、IDE 配置与较早重复的 docs/product-portfolio/。原文件仍在本地，仅不进入 Git。

产品证据目录中的测试记录是脱敏执行摘要，不包含原始控制台路径、密钥或私人的研究数据；历史测试计数不重新包装为当前大样本成绩。页面导出与评估夹具使用合成案例，真实报告图仅展示已登记的受限公开资料验证，不上传完整研究数据库。

## 发布检查

初始化前目录没有 .git、提交历史或远端，已检查当前 GitHub 账号的已有仓库，没有本项目仓库；按请求新建私有仓库。初始提交不虚构过去月份的 Git 历史。

2026-10-19 按作者要求将仓库改为 Public。变更前复核了当前可达的 317 个 Git 对象，未发现所检查的配置密钥或凭据标记；变更后未登录的仓库页面、元数据及 README 请求均返回 200。仓库公开不改变线上工作台的共享访问口令。

对待提交文件及文本容器（DOCX / PDF）进行环境秘密精确匹配、常见 token / 私钥 / 含口令 URL 检查；同时检查本地链接、允许路径、文件大小和应用 / 配置哈希。首次提交后遍历该提交可达 Git blob，确认没有被忽略文件或秘密进入历史，随后以普通 push 推送，不使用 force。

结果见 [上传质量检查](证据/上传质量检查.json)、[初始提交的 Git 历史检查](证据/Git历史检查.json) 和 [展示入口检查](证据/展示入口检查.json)。上传前再次检查包含验收记录的最终历史。扫描是多种规则与人工选择结合的发布检查，不声称能识别任意隐写或所有敏感信息。官方 Figma 链接保持默认权限，仓库公开不会自动开放 Figma 编辑权限。
