## 启动准备

Python 3.12—3.14、uv、Node.js 22+。先在根目录由 [.env.example](../../.env.example) 手动创建自己的 `.env`，填写 Qwen / DashScope、Tavily、X、Massive 及 SEC 联系身份；示例本身不含凭证。不要上传环境文件。

```powershell
Copy-Item .env.example .env
# 使用编辑器填写自己的配置；已有 .env 时不要覆盖。
uv sync --frozen
powershell -ExecutionPolicy Bypass -File scripts\start.ps1
```

打开 http://127.0.0.1:8765 。Windows 启动脚本首次下载独立 PostgreSQL、生成本地口令并运行迁移，不安装系统服务。数据库文件位于 `.runtime/pgdata`，仅本机监听 55432。原始环境文件、业务库和下载缓存不随仓库提供。

```powershell
powershell -ExecutionPolicy Bypass -File scripts\stop.ps1
```

停止应用保留数据库；`-Database` 同时停止本项目数据库。`start.ps1 -Dev` 重建前端。其他系统可自行准备 PostgreSQL / DATABASE_URL 并参考 [CLI](../../backend/app/cli.py)，Docker 配置提供但历史未启动验证。

## 分级验证命令

**无外部调用、无数据库写入：**

```powershell
.venv\Scripts\ruff.exe check backend scripts tests
.venv\Scripts\ruff.exe format --check backend scripts tests
.venv\Scripts\python.exe -m pytest -q
cd frontend
npm.cmd ci
npm.cmd run build
```

`npm ci` 安装依赖需网络；构建不消耗研究 API 额度。`pytest -q` 不启用数据库集成；其跳过数量必须保留在结果说明。

**自备本地 PostgreSQL 后的隔离集成验证：**

```powershell
.venv\Scripts\python.exe -m pytest --integration -q
```

tests/conftest.py 创建随机命名测试库并在结束后只删除该库；不要把该命令用于不允许创建 / 删除测试库的共享实例。本次上传检查未执行此命令。

**需要明确成本 / 写入范围的真实验收：** provider probe、live_smoke、live_actions 会访问真实服务；X 同步会保存公开帖子，研究消耗额度。脚本由使用者按自己的许可执行；不作为 clone 后自动运行步骤。浏览器测试需要运行应用与既有报告，部分用例拦截行情并使用隔离页面夹具。详见 [历史命令与结果](../validation.md)。
