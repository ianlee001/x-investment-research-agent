## 统一资料说明

本设计以现有 PRD 与离线原型为基准，以应用为实现参照。EXM、invest_demo、DEMO、EDIT、帖子、财务值、行情及来源 A / B 均为合成案例；行情交易日为 2026-08-14，资料截至 2026-08-15。来源发布时间与抓取时间分开，100 亿美元 = USD 10 billion；90 亿美元 = USD 9 billion。原型计时用于展示状态转换，不代表服务耗时或性能成绩。

原型支持原生点击、滚动、叠层开关、来源片段、预设参数编辑、组件切换与异常分支。输入、回复和保存反馈使用预设值；自由文本输入、实时联网、服务端持久化、下载文件和完整键盘焦点管理不列为已完成原型交互。原型中的批准仅切换合成页面，不操作应用数据库。文件保留默认权限，未执行公开共享设置。应用功能、配置和数据库未在本轮修改，未上传 GitHub。

## 产品与核心判断

面向阅读公开 X 美股观点、愿意核对依据的个人研究者。以用户选中的一条具体帖子为研究单位，降低原帖、披露、行情、新闻之间的查证负担。

关注公开账号 → 同步混合帖子 → 用户选择投资观点 → 点击核查 → 获取外部资料 → 阅读断言、支持与反对证据、来源、不确定性 → 继续研究。

生活内容保留在列表中，不自动作为投资观点；博主数量不构成事实证据。未来价格预测不能显示为已证实事实。图片内容未纳入本次文字核查的提示紧邻帖子及报告范围。Agent 提议修改个人资料必须由用户作出决定，批准与执行结果分开显示。

桌面采用 240px 主导航与独立主内容；账号和标的页面有辅助列表。手机重新组织为文字导航折行、列表与正文纵向排列、主要操作纵向展开。页面宽度分别为 1440px 与 390px。设计原稿保留完整内容高度，演示画板使用 1000px / 844px 可滚动视口。

报告按摘要、断言覆盖、逐条断言、双向证据、不确定性、追问、来源和活动组织。来源叠层关闭后保留报告阅读位置。取消先显示正在取消，再显示确认结果；重试进入 RUN-DEMO-02，结果和继续研究上下文使用同一新编号，旧报告仍可从工作台进入。

## 基础样式与组件

Noto Sans SC：正文 16/26、辅助 14/22、标题 28/40、手机标题 24/34、段落标题 20/30、指标 32/44。深色正文 #17212B，次级文字 #465463，主操作 #3155C9，白色卡片与 #F5F7FB 背景；状态均有文字标签。主按钮高度 44px。

建立两组变量集合，合计 56 个原始值与语义变量；8 个文本样式；11 个组件集与 4 个独立组件，共 58 个主组件或变体。组件表包含编辑字段和节点链接，见[组件清单](组件清单.csv)。颜色与间距绑定到语义变量；文案使用可编辑文字及组件文本属性。所有界面均由原生图层组成，图片仅作为本地导出预览，不在 Figma 中充当界面底图。

间距采用 4、8、12、16、20、24、32、40、48；圆角采用 6、8、12。按钮、字段、卡片、帖子、断言、证据、导航、开关、审批、空状态、进度与弹窗均复用组件。设置开关以组件内 Change to 双向切换。

## 集中设计决策

| 编号 | 选择与依据 |
|---|---|
| D01 | 七页名称采用本次产品任务用语，保留 P01—P07 与 REQ 编号；“X 情报 / 研究 / 关注标的 / 对话 / 审批”是应用中的对应名称。 |
| D02 | 应用使用系统字体栈，Figma 使用已验证可用的 Noto Sans SC；依据字号与行高规范保持中文阅读层级。 |
| D03 | 颜色以 PRD 的深色文字为基准；次级信息保留可读性，不用浅色小字承担来源与单位。 |
| D04 | 行情只展示上一交易日示例；+2.04% = (100 / 98 − 1) × 100%，明确标为较当日开盘，不误标为较昨收。 |
| D05 | 正反证据同层可达；100 亿与 90 亿冲突不通过计票消除；预测和意见分别解释不可作为事实核实的原因。 |
| D06 | 任务取消与终态、新研究与旧报告、审批决定与实际执行分别呈现；来源关闭保留阅读位置。 |
| D07 | 演示场景入口独立于应用导航；空状态、行情失败和校验错误集中在“其他页面状态”，不污染正常页面。 |
| D08 | 不添加图片理解、周报和外部推送能力展示；这些仍按 PRD 的 EXT-01—03 作为扩展设计。 |

## 可读性迭代

触发场景是本人阅读帖子、报告与设置时遇到浅色小字和冗余说明。留存样式含 7—12px 字号；当前目标采用正文 16px、辅助至少 14px，删除重复功能解释，保留来源、日期、单位、审批参数与期限。

06 页使用同一合成内容制作“样式重建对照”：12px 浅色示例与修订目标并列，原生文字均可编辑。它不是历史截图，也不声称精确重现整页历史布局。旧样式示意中的四段文字专门作为问题展示，不纳入目标页面可读性通过范围。真实应用迭代已有七页两宽度、关键弹窗和最终 6 项浏览器测试记录；未编造耗时、满意度或提升比例。

## 检查与交付结果

目标界面与原型的可见文字最小 14px，计算到的最低文本对比度 6.42:1；未发现非预期横向越界。结构检查采用递归读取实例子图层，避免遗漏组件内部操作。所有原型目标存在，所有演示画板均可从起点到达，叠层有关闭或返回操作。结果见[结构检查](结构检查.json)与[实际原型核验](实际原型核验.md)。该检查范围不等于完整 WCAG 认证。

交付包含七页桌面与手机设计、58 张关键状态稿、两个原型起点、可读性迭代、21 张关键导出 PNG、两个缩略总览、组件与需求追溯 CSV、节点索引与本地 HTML。招聘展示建议先看原型主路径，再看 P03 / P06 的产品判断，最后追溯 PRD 与代码。
