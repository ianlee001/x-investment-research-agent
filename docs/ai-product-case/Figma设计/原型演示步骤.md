# 原型演示步骤

[桌面起点](https://www.figma.com/proto/5satRUZqhVo53GQJXfttHw?node-id=12-1270&page-id=5%3A6&starting-point-node-id=12%3A1270&scaling=scale-down-width&content-scaling=fixed)｜[手机起点](https://www.figma.com/proto/5satRUZqhVo53GQJXfttHw?node-id=12-2747&page-id=5%3A6&starting-point-node-id=12%3A2747&scaling=scale-down-width&content-scaling=fixed)

## 1. 单帖核查

1. 选“完整核查流程”，进入账号空状态。
2. 点“添加公开账号”，提交预设 invest_demo。
3. 点“同步帖子”，经历加载后看见投资帖与生活帖。
4. 选投资帖的“核查观点”；等待状态过渡到报告。
5. 比较收入冲突，查看未来预测与个人意见的类型边界。

## 2. 引用与继续研究

1. 在报告展开第一条断言，阅读支持与反对证据。
2. 点“定位来源片段”或来源列表，检查时期、单位、发布时间与抓取时间。
3. 点“返回报告”或“关闭”，回到原阅读位置。
4. 点“携带报告继续研究”，在 P05 查看上下文归属；可移除上下文，或发送预设问题查看回复。

## 3. 取消、部分结果与失败

1. 从起点选“取消与重新研究”，在研究运行时点“取消研究”。
2. 页面先显示“正在取消”，再显示“研究已取消”；可看已取得资料。
3. 点“重新研究”，进入 RUN-DEMO-02；新结果与继续研究上下文保持同一任务编号。
4. 从起点分别选“部分结果与重试”“研究失败与恢复”，检查资料保留和重试入口。

## 4. 人工审批

1. P05 点“加入关注列表”，或从起点选“人工审批分支”。
2. 查看 DEMO、公司名称、备注、原因、期限、决定及执行状态。
3. 拒绝路径：点“拒绝” → “确认拒绝”；结果是已拒绝、未执行。
4. 编辑路径：点“编辑并批准” → 点击代码字段选择预设 EDIT → “保存修改并批准”。
5. 先看执行中，再看已执行；“查看关注列表”进入含 EDIT 的示例状态。
6. 从起点选“执行失败”或“审批过期”，查看未保存、重新提出意图及禁止旧执行的状态。

## 5. 导航与其他状态

七个文字导航可在工作台、帖子、报告、行情、对话、审批与设置之间切换。设置开关支持开启 / 关闭双向切换，保存显示预设反馈。“其他页面状态”可看无报告、无标的、无审批、行情失败和账号错误；弹窗可关闭。

重新打开本页顶部的演示链接可回到场景入口。字段输入与保存的演示范围见[设计说明](设计说明.md#统一资料说明)。
