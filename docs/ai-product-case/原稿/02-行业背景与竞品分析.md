# 行业背景与竞品分析

## 研究问题与资料范围

研究问题是：投资内容发现、资料搜索与观点核查分别由哪些产品解决？用户完成一条观点核查时，在哪些环节仍需自行拼接？比较维度围绕任务而非功能数量，包括入口、资料组织、引用定位、观点与事实的区分，以及持续追问。

FINRA Foundation 2026 年研究简报使用 NFCS 投资者调查，显示 2024 年受访投资者中约 29% 较多使用社交媒体或讨论板获取投资信息，26% 至少有时参考金融影响者。它说明社交投资信息具有研究意义，不证明本产品的市场规模，也不能外推为中国 X 用户需求或因果关系。[FINRA 官方简报](https://finrafoundation.org/sites/finrafoundation/files/2026-03/FINRA_Foundation_Research_Brief_Social_Media_Finfluencers.pdf)

## 任务型竞品比较

| 路径 | 官方可确认的能力 | 本任务中的选择依据 |
|---|---|---|
| 手工使用 X、搜索、行情、SEC | 用户分别阅读帖子、披露与行情；SEC 提供公开披露数据接口。 | 控制直接，但需要自行保存断言与证据关系；作为任务基线，不给未经测量的耗时结论。 |
| AlphaSense Generative Search | 自然语言提问、按公司或时间等缩小范围、生成带引用的回答、定位原文并继续追问。 | 借鉴检索范围与引用定位；本项目把“特定公开帖子”作为任务入口。未进行同题付费实测。 |
| Stocktwits Sentiment | 官方介绍展示社区情绪、热门标的与讨论洞察。 | 将观点分布与事实核查分层；不以情绪信号替代外部证据。 |
| X 投资观点研究助手 | 单帖进入、原子断言、证据方向、时间口径、冲突与不确定性、审批。 | 以清晰的核查对象和证据链组织体验，优先闭合个人任务。 |

竞品功能依据 AlphaSense 的[官方交互说明](https://help.alpha-sense.com/hc/en-us/articles/41666587181203-Interacting-with-Generative-Search)与 Stocktwits 的[官方产品介绍](https://stocktwits.com/about)，比较聚焦可核对的产品任务与组织方式。

## 方案选择与放弃项

保留账号追踪，减少每次寻找研究对象的重复操作；保留人工选帖，让用户控制相关性与调用成本；保留断言级证据，避免只有整篇摘要却无法复核；保留行情辅助页，明确其交易日与价格口径。

不将全量自动研究、情绪预测或交易执行纳入首版：它们扩大成本和责任范围，不能直接提高单帖核查的可解释性。V1 采用受限工具集，不增加 RAG、向量库、文档上传解析和多 Agent 架构，因为主任务依赖可更新的外部资料与单次研究上下文。

## 结论与检验方式

差异化假设是“以一条观点为单位组织证据”能够降低研究过程中的信息断裂。验证应让使用者完成同一任务，检查能否正确回到来源、区分预测与事实、识别冲突；不能通过竞品功能表宣称效率优于专业平台。
