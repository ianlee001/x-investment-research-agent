# Tremor components

AreaChart and its helpers are copied from the official Tremor repository:
https://github.com/tremorlabs/tremor

Licensed under Apache-2.0; the full license is included alongside these files.
Local modifications: relative import paths, Recharts 3 type compatibility, accessible chart typography through application CSS, and HeroUI Button for legend scrolling with press/hold and keyboard support.

Official usage and installation:
https://www.tremor.so/docs/visualizations/area-chart
